## ✨ Features

- **Luxury Editorial Aesthetic**: Midnight Teal (`#062C2C`), antique gold accents (`#C8A96A`), warm cream tones, and Cormorant Garamond typography.
- **Hero Carousel**: One-image-at-a-time slide carousel featuring Rwandan Red Bourbon signature pours, slow-chill nitro cold brew, and iced caramel swirls.
- **Rwandan Single-Origin Story**: Celebrating harvests from Huye Mountain, Lake Kivu, Gakenke, and Maraba.
- **Interactive Curated Menu**: Category filtering with pricing in Rwandan Francs (FRW).
- **Product Customization Modal**: Dial-in your milk options (Barista Oat, Rwandan Inyange Whole Milk), ice levels, sweetness, and extra ristretto shots.
- **Interactive Slide-Out Bag (Cart)**: Dynamic cart, quantity adjustments, table-service vs. express takeout selector, and 18% Rwanda VAT calculation.
- **Table Reservation Sanctuary**: Interactive booking form for Kigali guests (Kimihurura solarium lounge, quiet study nooks, or terrace).
- **Moments of BrewHaven Gallery**: Editorial grid with uniform aspect cards and full-screen image lightbox.
- **Cinema Story Modal**: 3-chapter visual storytelling journey from sunrise mountain harvest to the velvet microfoam pour.
- **Instant Search**: Quick modal filter across drinks, beans, and roast profiles.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/brewhaven-kigali.git
cd brewhaven-kigali
```

### 2. Install dependencies
```bash
npm install
# or with bun
bun install
```

### 3. Start development server
```bash
npm run dev
# or
bun run dev
```

Open `http://localhost:3000` to view the website in your browser.

### 4. Build for production
```bash
npm run build
```
